# プライバシーポリシー（Privacy Policy）

最終更新日：2026年10月17日

UYING MEDIA LIMITED（以下「当社」）は、ショートドラマサービス「Aurora Drama」（以下「本サービス」）におけるユーザー情報の取扱いについて、以下のとおり定めます。

## 1. 収集する情報

- アカウント情報：TikTok ログインにより取得するユーザー識別子（open_id）、ニックネーム、プロフィール画像
- 利用情報：視聴履歴、購入履歴、サブスクリプション状態
- 技術情報：端末種別、OS、アプリバージョン、利用時間

## 2. 利用目的

- サービスの提供・運営（視聴権限の管理、購入コンテンツの配信）

- お問い合わせ対応

## 3. 情報の共有

法令に基づく場合を除き、ユーザーの個人情報を第三者に販売・提供しません。決済処理のため、TikTok プラットフォームとの間で必要な情報をやり取りします。

## 4. 情報の保管と安全

当社は、収集した情報を安全に保管し、不正アクセス・漏えい・改ざんの防止に努めます。

## 5. ユーザーの権利

ユーザーは、自己の情報の開示・訂正・削除を当社に請求できます。

## 6. 未成年者について

本サービスは、適用される法律に基づき年齢制限を設ける場合があります。未成年の方は保護者の同意を得た上でご利用ください。
