# 市场调研：TikTok Minis 与短剧 / 漫剧出海全景

> 调研时间：2026 年 10 月 · 数据来源：DataEye、Sensor Tower、点点数据 / 短剧自习室、Appfigures、中航证券研报、行业媒体（白鲸出海、36 氪等）
>
> 本文是「漫剧 Minis」立项的核心输入：搞清楚 **TikTok Minis 里谁在赚钱、在哪国赚钱、靠什么界面和付费模式赚钱、内容长什么样**，再决定我们的漫剧小程序怎么做。

## TL;DR（一页看懂）

- **TikTok Minis**：TikTok 站内小程序（海外版抖音小程序），2025-12 正式上线、2026 开年全面铺开。短剧小程序已超 **13 个**，把「视频 → 跳浏览器 → 下载 App」的长漏斗砍成「点锚点 → 站内直接看 + 付钱」。
- **谁最赚钱**：付费 App 呈 **ReelShort / DramaBox / DramaWave 三足鼎立**；但 Minis 站内目前是 **ShortMax、NetShort、Stardust TV 等中腰部**先入局（头部在观望，怕失去变现链路控制权）。
- **哪国最赚钱**：**美国断层第一**（2025 全年超 11 亿美元、占近一半；RPD 11.26 美元是其他市场 6 倍），**日本第二**（约 4.8 亿美元），英国第三；**印度/印尼/巴西**贡献 7 成下载量但收入微薄（靠广告变现）。
- **付费模式三件套**：免费前 8-10 集 + **单剧解锁约 10 美元** / **订阅 40-80 美元月费** / **金币按集解锁**（38 美元 = 500 金币）。平台初期**不抽佣 + T+1 提现**。
- **漫剧是 2026 最猛变量**：AI 漫剧承制价从每分钟 4000-5000 元跌到 **300-500 元**，海外市场规模从 2025 年约 1 亿美元冲向 **6.5 亿美元**；海外投放消耗中真人:AI 已是 **2:8**。**北美观众对 AI 换脸真人剧违和感强、对漫剧接受度高**——这正是我们做漫剧 Minis 的机会窗口。
- **行业真相**：约 90% 公司在亏损边缘（投流成本吃掉收入 60-80%），钱被 Meta/Google/TikTok 等「流量地主」赚走。能赚钱的三种人：**手握网文 IP 库的、精通本地情绪点的、起早建账号矩阵的**。

## 一、TikTok Minis 是什么（与我们项目的关系）

TikTok Minis 是运行在 TikTok WebView 里的 **H5 Web App**，通过 `window.TTMinis` 调用登录 / 支付 / 广告等客户端能力，用 minis-cli 调试打包——这正是本项目的技术底座（详见 [README 官方文档](https://github.com/seanliii/tiktok-minis-drama#官方参考文档lark)）。

**为什么重要**：TikTok 月活超 10 亿，短视频挂 Minis 锚点组件后转化路径缩短约 80%，流量成本远低于独立 App 买量；TikTok 小游戏次日留存 14%，高于 Facebook 小游戏的 10%。

### 演进时间线

| 时间 | 事件 |
| --- | --- |
| 2022 | TikTok 首次测试 7 款小游戏 |
| 2025-05 | 二次测试：8 款小游戏 + 3 款短剧 |
| 2025-11 前后 | 字节 Melolo 在东南亚上线（免费 + 广告路线） |
| 2025-12 底 | **TikTok Minis 正式上线**，短剧小程序超 13 个，短剧获一级入口 |
| 2026 开年 | 商业化路径清晰：IAA/IAP 混合、T+1 提现、不抽佣扶持期 |
| 2026-04 | TikTok 短剧单月分账突破 1500 万美元（Business Account 路线） |
| 2026-05 | 单月分账 2100 万美元，其中 AI 短剧 650 万 |
| 2026-07 | 单月分账 2900 万美元 |

### 用户入口与界面样式

两个入口，体验「像回到国内抖音小程序生态」：

- **搜索入口**：TikTok 搜索 `Minis` 或具体小程序名 → 出现 Minis 板块，首次使用后**自动固定在个人主页**
- **主页入口**：主页右上角菜单 → `TikTok Minis` 查看全部小程序
- **视频锚点**：短视频挂载 Minis 组件，点击即用，无需跳转 / 下载

**短剧小程序内部典型界面**（以 TikTok 自家 LimeShorts 为参照，各家大同小异）：

| 区块 | 样式与内容 |
| --- | --- |
| 首页顶部 | Logo + 搜索框 |
| 底部导航 | 首页 / 播放列表（Continue Watching）/ 个人中心 三 Tab |
| 首页主体 | 竖屏封面瀑布流 + 轮播 Banner，按题材分标签（霸总、狼人、豪门、逆袭、美式高中…） |
| 个人中心 | 金币余额、奖励金领取、订阅管理 |
| 通用功能 | 免费集进度、15 秒激励视频解锁、金币按集解锁、每日签到领币、多语言字幕 + AI 配音 |

LimeShorts 产品设计简洁：首页顶部仅 logo 和搜索框，奖励金入口藏在个人主页标签中；内容以真人短剧为主，热门列表前列以**本土剧**为主、兼有译制剧。

### 技术约束（对我们直接相关）

- 资源体积 **< 45MB**，HTML5 视频播放，请求域名须平台白名单
- 已有 H5 短剧应用（如 uni-app）可低成本适配：H5 输出 + TikTok Web SDK（一键登录 / 激励视频 / 支付回调）
- 媒资优先用平台媒资库播放器，省转码与 CDN 成本
- 支付依赖企业认证 + IAP 开通 + Webhook 地址配置

## 二、付费模式拆解

### 短剧小程序标准三件套

| 模式 | 定价 | 说明 |
| --- | --- | --- |
| 单剧解锁（IAP） | 免费 8-10 集 → **约 10 美元 / 部** | 国内「卡点付费」直接平移 |
| 订阅 | **月费 40-80 美元**无限看 | TikTok 自家 LimeShorts 在美测试周订 / 年订 / 金币混合（商店页显示周卡 158、年卡 1559 美元的测试价，官方声明价格会变动） |
| 金币体系 | **38 美元 = 500 金币**，单集约 66 金币 | 复用 TikTok 直播打赏虚拟币体系（2024 年 TikTok IAP 总收入 60 亿美元），推广期 10% 折扣 |

### 平台侧政策（窗口期红利）

- **不抽佣 + T+1 提现**：对比传统渠道 30-60 天结算，资金周转效率提升 93%
- **广告分成测试中**：平台向制作方提出「最高 1 万美元授权费 + 广告分成」换整剧免费发布——即国内红果短剧（月活 2.36 亿）的免费 + IAA 模式出海
- **游戏合伙人计划已启动**：达人内容挂载小程序入口，用户点击即玩/即看——内容与小程序边界被打破

### 另一条路：Business Account 分账

不发小程序，用 Business Account 发布 Drama Series 参与平台分账，更适合**先低成本测内容**：

| 月份（2026） | 单月分账 | 备注 |
| --- | --- | --- |
| 4 月 | 1500 万美元 | AI 短剧分账超 200 万（Q1 总和刚过 200 万） |
| 5 月 | 2100 万美元 | AI 短剧占 650 万；18+ 部 AI 短剧单月分成超 5 万美元 |
| 7 月 | 2900 万美元 | 本土 AI 剧同比增长 34% |

单部头部 AI 剧半月分账 10-20 万美元（《Bestie, I'm Going to Fight Back》半月 18 万美元；《Make Him Grovel》播放破 1 亿、分账 13 万美元，41% 观众来自美国）。

::: tip 两条路怎么选
新团队先用 **Business Account** 测题材 / 封面 / 解说 / 留存（内容发行逻辑）；有预算、有产品承接、有稳定内容供给后再上 **Minis**（站内经营一款短剧应用，收入想象力更大但更重）。
:::

## 五、漫剧：2026 年最猛的新变量 ⭐

**漫剧 = AI 制作的动漫短剧**（漫画分镜 + AI 配音 + 动态化）。真人短剧要请演员、租别墅、办签证；漫剧是「几个人对着电脑输提示词把网文变成动画片」。

### 成本雪崩

| 指标 | 变化 |
| --- | --- |
| 承制价 | 每分钟 4000-5000 元 → **300-500 元** |
| 单剧成本 | 压到 10 万元级，周期 7-14 天 |
| 翻译环节 | AI 工具降本 40-80%（一集 10 分钟翻译从 2-3 天压到 8 分钟） |
| 整体制作 | 跨文化表达成本节省 90%+，整体成本压至原先 1/15 |

### 市场数据

- **国内**：2026 Q1 国产微短剧产量里 **AI 漫剧占 95%**；市场规模 2025 年 168 亿元 → 2026 预计 240 亿元+
- **海外**：2025 年约 1 亿美元 → **2026 年预计 6.5 亿美元**；素材投放榜 Top100 里 AI 剧占比三个月翻了七八倍
- **替代效应**：真人短剧实拍项目同比缩减 30-50%；海外投放消耗真人:AI = **2:8**（2026 Q2 三个月内完成逆转）
- **TikTok 分账**：AI 短剧从 2026 Q1 总分成刚过 200 万美元 → 5 月单月 650 万，一个季度从边缘品类变核心引擎

### 为什么漫剧比 AI 真人剧吃香（对我们最关键）

美国电影协会亚太区副总裁点破：**北美观众对 AI 换脸真人剧容易产生「品质不佳」印象；漫剧违和感低，中国本土 IP 漫剧在北美具备巨大发展潜力。**

### 用户画像互补

| | 真人短剧 | 漫剧 |
| --- | --- | --- |
| 性别 | 女性占 67.5% | **24-30 岁男性为主** |
| 题材 | 霸总 / 豪门 / 复仇 / 狼人 | 玄幻 / 脑洞 / 热血 / 系统流 |
| 相当于 | 「她经济」视频版 | 多挖一座男性向的矿 |

### 玩家动态

九州文化（AI 剧 + 漫剧占总产能 95%，投超 1 亿元采购网文版权）、昆仑万维（DramaWave 动漫频道）、字节 / 腾讯 / 阿里 / 快手全部入局；招聘市场上网易、边锋等游戏厂商大量招漫剧岗位。

## 六、内容形式与题材

- **真人短剧**：竖屏、每集 1-2 分钟、一部 80-100 集；题材 = 情绪钩子（被弃妻子逆袭、豪门复仇、恶毒千金打脸、狼人霸总、美式高中恋）。**本土剧播放量是译制剧的 3-5 倍**，本土剧占比已从不到 2 成飙到 36%（2026 年 1-2 月）
- **漫剧**：漫画分镜风，玄幻 / 脑洞 / 热血，男性向
- **AI 剧工业化**：平台「月万分钟计划」要求供应商月产一万分钟；OST 传媒铺了 80+ 个 AI 账号矩阵
- **TikTok 官方自制**：与好莱坞 Hoorae Media 合作的竖屏短剧《Screen Time》首周播放近 7500 万；与圣丹斯学院合办微短剧编剧项目
- **用户习惯已成型**：全球短剧应用日均使用 25 分钟（同比 +85%）；用户总时长是一年前近 6 倍；付费意愿从 40.5% 提升到 48.8%

## 七、入局门槛与行业真相

### 准入（美区是「鬼门关」）

| 主体 | 能否上美区 | 备注 |
| --- | --- | --- |
| 中国大陆 | ❌ | 注册阶段即被拦截 |
| 中国香港 | ❌ | 最新实测同样被拦 |
| 新加坡 | ✅ | 需过 USDS 审查，备选跳板 |
| 美国 | ✅ | 最优：信任等级最高、结算最顺 |

入驻流程：企业认证（Business Verification）→ Mini Drama 行业资格审核（交代表作 + 版权证明）→ Developer Organization → 创建 App → 开发测试 → 审核 → 发布（灰度 / 正式）。美区另有 Launch Approval 额外要求。USDS TPRM 四大常见被拒原因：主体信息不一致、区域能力未开通、资料不规范、商业化链路未闭环。

### 行业真相（泼冷水部分）

- **约 90% 公司在亏损边缘**，80-90% 出海项目无法回本；投流成本占收入 60-80%
- ReelShort 母公司枫叶互动 2025 H1 营收 3.84 亿美元（+270%）但**净亏损 4651 万元**；昆仑万维前三季度净亏 6.65 亿元；中文在线单季销售费用率 87%
- 赚钱的是「流量地主」：Meta、Google、TikTok
- 留存是硬伤：美国 D1 27% / D7 10% / D30 2%
- 制作成本在涨：海外自制剧单集从 8-15 万美元升至 20 万（年底或 30 万）——**AI 漫剧正是对这个成本问题的回答**

在「90% 不赚钱」的格局下，两类玩家活得好：① 有用户资产和平台运营能力的**平台建设者**；② 轻资产、向多平台输出内容的 **IP 提供商**。漫剧 Minis 的定位 = 用 AI 漫剧的成本优势 × Minis 站内闭环的转化效率，切日本 / 美国等漫剧接受度高的高 ARPU 市场。
:::

## 八、对我们项目的启示

1. **题材**：男性向玄幻 / 脑洞 / 系统流漫剧为主力，可留女性向漫剧位测试（真人短剧女性用户 67.5% 的盘子漫剧也能切一部分）
2. **市场优先级**：日本 / 美国（高 RPD + 漫剧违和感低）> 韩国 / 欧洲 > 东南亚（IAA 广告补充）——与现有 M 包（US 等）/ T 包（JP 等）调试分区天然对齐
3. **付费设计**：金币按集解锁为主轴（38 美元 = 500 金币档位），免费前 8-10 集 + 订阅 40-80 美元/月 档位参照；预留激励视频解锁（IAA）作为低付费市场的兜底
4. **界面基线**：三 Tab（首页 / Continue Watching / 个人中心）+ 瀑布流 + 题材标签 + 金币余额 + 签到领币，即行业通用范式
5. **内容供给**：AI 漫剧工业化产能（单剧 10 万元级 / 7-14 天周期）+ 网文 IP 库是成本护城河；本土化不只是翻译（本土内容播放量 3-5 倍于译制）
6. **风控**：美区走新加坡 / 美国主体 + USDS 审查提前准备；投流 ROI 模型按「收入 60-80% 被投流吃掉」的悲观假设做压力测试
