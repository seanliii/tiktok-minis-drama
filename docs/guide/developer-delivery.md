## 2. 如何在其他开发机复现

**先取得团队授权的最新版代码交付。** 本次公开网站只同步文档；公开仓库中原有的旧应用目录并未自动更新为本页描述的完整前后台。不要仅凭网页已更新就认为克隆公开 `main` 能运行全部新功能。最新业务代码当前在本机功能分支，源码、私有配置与数据的异地交付需按团队指定的私有渠道另行完成。

从项目根目录进入 `app/tt-minis`。推荐 **Node.js 22 的最新补丁版本（至少 22.13）**，也接受 Node.js 24；以锁文件安装。本轮实际验证环境为 Node.js 22.23.2：

```bash
npm ci
npx playwright install chromium webkit
npm run test:all
npm run local
```

用户页：`http://127.0.0.1:5310/#/`；管理页：`http://localhost:5310/admin/`。初始随机管理员位于 `.local/admin-credentials.txt`。**不要双击 `index.html`**，完整服务必须通过 HTTP 启动。

- `npm run local`：构建并启动前后台完整服务；后续 `npm start` 即可，不丢数据。
- `npm run dev`：普通浏览器用户页开发，通过代理连接 5310 业务服务；需同时运行 `npm run dev:server`。不加载 TikTok SDK。
- `npm run dev:admin`：独立后台开发，默认 5174；管理员登录不是 TikTok 开发者平台的账号密码。
- `npm run build:preview`：生成 `dist-preview/`，含本地测试视频，无需 TikTok 账号即可检查播放器。
- `npm run preview:demo`：仅展示 `dist-preview/`，不包含业务服务。
- `npm run test:unit`：分别固定离线与服务模式的账户、SDK、网络失败及本机存储单测。
- `npm run test:server`：独立临时数据库下的权限、文件、订单、退款、持久化与支付接口边界。
- `npm run test:admin`：管理网页的交互、权限和真实本地服务检查。
- `npm run test:media`：已有平台剧目的管理、版本同步与发布检查；替换外部平台，不实际提审或上下架。
- `npm run test:sessions`：WebKit 下真实应用会话、跨站无 Cookie、同源 GET/HEAD、续期、退出和换号检查。
- `npm run test:fullstack`：用户与管理员在 Chromium／WebKit 中走完整业务。
- `npm run test:e2e`：先构建预览包，再用浏览器执行用户流程；不是对开发热更新服务截图后猜测通过。

### 平台候选包

```bash
npm run build:minis
npm run check:minis
```

当前工程固定使用官方主流程 **`tiktok-minis-cli@0.0.7` → `minis build`**，不再将旧 `ttdx` 教程与新 SDK 混用。CLI 会输出实际 zip 路径；打包在本地，不会上传。

- `dist/`：平台候选产物，首个脚本为 TikTok SDK，包含平台配置，不包含预览视频。
- `dist-preview/`：浏览器离线体验产物，**不要上传到 TikTok**。
- `dist-service/`、`dist-admin/`、`dist-server/`：业务服务的三份产物，不能当作 Minis 代码包上传。
- 官方包大小限制以当前文档和实际上传页面为准，不沿用旧资料中的固定 30 MB／50 MB 说法。
- CLI 依赖中存在被固定到旧版的工具库，工程用同主版本安全补丁的 `overrides` 修正；变更后需同时跑审计、构建与浏览器测试，不可只看 `npm audit`。

`npm run dev:platform` 保留端内联调模式：不提供浏览器测试视频。真实客户端连接、SDK 兼容和鉴权并未因此自动完成；管理员和开发方应按照当时的官方开发工具说明进行联调。

## 7. 不要混淆的完成状态

1. **网页离线通过**：证明 UI 和本地可测试行为；不证明手机 SDK、真实短剧或付款。
2. **官方 CLI 构建通过**：证明当次文件结构／脚本／大小等工具检查；不证明业务可上线。
3. **端内预览通过**：证明特定测试账号和设备的结果；不等于普通日本用户已能用。
4. **提审成功**：以平台实际提交状态为准，不看某次 HTTP 200 就算完成。
5. **审核通过并发布**：再进行普通用户访问和内容／支付回归，才算正式上线验收。
