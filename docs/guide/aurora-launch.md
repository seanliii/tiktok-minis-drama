## 3. 为什么现在不直接打开日韩东南亚

“以后做日韩东南亚”是产品方向，不是说这次就同时发布到所有市场。

当前应用仍使用日文界面和日本片库筛选。已经有 `language` 和 `regions` 字段，但消费者页面及部分服务端规则仍按 `ja`／`JP` 实现，**不能只勾一个国家，就宣称本地化全部做好**。

扩展每个市场时，需要同步完成：

1. **国家与语言**：韩文、泰文、印尼文等对应界面、分类、字幕／配音、客服与条款；东南亚不是单一语言或单一地区。
2. **内容授权**：确认每部剧在该市场的版权、发行范围及内容要求，不把日本授权自动当作其他地区授权。
3. **片库与价格**：按市场返回内容、免费范围和可售商品；保留用户已购权益，不串用其他市场的定价和记录。
4. **平台配置**：目标国家在该 App 下的实际可选性、审核和支付能力，逐项核实，不能从其他应用复制状态。
5. **测试与发布**：各市场真机、语言排版、登录、播放、支付、退款与客服测试后，再分批开放。

后续可以继续使用这个 Aurora 应用及共用的运营后台，不需要每上传一部新剧就开发一个新 Mini；是否某地区需要额外应用或独立部署，以届时平台能力和团队决定为准。
