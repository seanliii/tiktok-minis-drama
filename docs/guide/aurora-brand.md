本次在已有深色＋珊瑚色基础上改进，服务于 **Aurora Drama 日本首发、之后扩展韩国和东南亚**。没有复制竞品的标记、封面或剧集；这是项目的原创图形，不代表商标检索或日本用户识别测试已经通过。

## 2. 新标记的设计

- **外轮廓为简洁的 A**：与 Aurora 名称对应，不依赖字型字体是否安装。
- **中间是向右的播放开口**：让标记与看剧发生联系，不只是一枚普通字母。
- **底部折带有轻微起伏**：延续极光带的方向感；不用多层透明光效，避免缩小后糊成一团。
- **背景保持完整深色方形**：1024×1024 提交图片本身没有透明圆角、水印、二维码或小字。
- **品牌色用于识别，不是内容状态**：红／橙色标记不代表已付款或已审核；成功、警告仍用明确文字与对应状态。

图形颜色延续项目原有的 `#ff3b5c → #ff7a45`，深背景为 `#20202b → #101017`。这些颜色不是从竞品取样复制。

## 3. 使用规则

1. App 图标、用户首页与管理后台使用同一图形。已知旧 `DV`／`AD` 文字占位应替换，不能让用户以为进入了另一款应用。
2. 主字标保持 **Aurora Drama**；日本标签可以在页面显示 `JP`，但不焊进图标，以便后续扩展。
3. 32–48px 的小位置只使用图形；较宽位置结合品牌全称。不要在小图标内再塞“短剧”“JP”或标语。
4. 功能按钮保留简明、同系列的图标与文字标签，不将品牌 A 用作播放／付款等操作按钮。
5. 会话 Cookie、接口请求标记、存储键和旧业务数据不随视觉改名，避免改品牌却让用户退出或丢失收藏。
6. 品牌渐变是装饰图形，不直接当作白色小字按钮的可读性证明；文字控件须单独检查对比度和焦点。

本轮接线将用户首页、后台登录／侧栏和无封面占位统一到 `AuroraMark`。首页“主页”使用同系列家形图标，不再用火焰代替主页。主要按钮及选中分类使用较深的同色系 `#c42d49` 承载白字，品牌图形仍保留原渐变。浏览器实测选中分类文字对比不低于 4.5:1；这不是全站无障碍认证。

## 4. 实际验证与范围

- 本地生成了 1024px PNG，以及 32／48／64／128／256px、灰度、单色和圆形裁切预览。
- 主任务已直接查看小尺寸预览：32px 下轮廓和播放开口仍可区分；这是视觉检查，不是用户识别率测试。
- PNG 为 RGB、无透明通道；原版 SVG／PNG 另存于本机，未丢弃。
- 同一 SVG 重复渲染的输出哈希相同；原生图形不依赖远程图片、字体、脚本或滤镜。
- 本地计算了颜色对比，但没有将其称作全站无障碍认证。

## 5. 体验对标应落在哪些实际行为上

| 维度 | Aurora 当前验证方式 | 仍需真实平台验收 |
| --- | --- | --- |
| 找剧 | 日文搜索、题材、详情和空结果恢复已有浏览器测试 | 日本真实片库和文案质量 |
| 免费边界 | 前端显示免费／锁定，后端拒绝无权播放 | 实际商品定价、免费集数与运营策略 |
| 续看 | 数据库观看记录、退出重登和跨账号隔离已测 | TikTok 两台真机与不同网络 |
| 支付透明度 | 取消不假成功、回调不直接发权、服务器确认后返播已测 | 官方沙箱、真钱支付与退款 |
| 内容运营 | 上传、核验、草稿导入、平台登记与版本查询继续接通 | 真实 BytePlus、字幕审查、上线内容 |
| 品牌识别 | 单一图形、字号和小尺寸检查 | 日本用户访谈／识别测试，以及正式商标核查 |

不为模仿竞品而加入虚假的榜单、观看量、赠币或“永久免费”。功能与承诺以真实数据和平台能力为准。
