# Apple Team ID：不用先下载 App，先查公司有没有现成团队

核对日期：**2026-10-19（北京时间）**。本页用于 Aurora Drama 的资料准备，不表示已经替公司注册、付费或取得 Apple Team ID。

## 1. Team ID 是什么

Team ID 是 Apple 分配给开发者计划会员的 **10 位字母数字标识**，不是邮箱、Apple Account 登录名、阿里云账号 ID，也不是公司的 9 位 D‑U‑N‑S 编号。

它不是一个脱离开发者会员而单独申请的编号。不要把个人免费开发团队、别人的编号或邮箱填到公司的 TikTok 资料中。

## 2. 如果公司已有 Apple 开发者会员

请公司账号持有人或能访问该团队的管理员：

1. 在浏览器打开 [Apple Developer 账号](https://developer.apple.com/account/)。
2. 登录公司团队对应的 Apple Account；如果可以切换团队，先选择正确的公司。
3. 打开 **Membership details（会员资格详情）**，查看并提供 Team ID。

不需要重新购买会员，也不必为了查看编号安装 Xcode、Apple Developer App 或升级 macOS。

## 3. 如果公司还没有会员

可以从 [Apple Developer 网页注册入口](https://developer.apple.com/programs/enroll/)点击 **Start your enrollment** 开始。

本项目运营主体已确定为公司时，应由其有权代表使用 **Apple Developer Program 的 Organization（组织）类型**申请；不要为了快而把团队放到外包开发者个人名下，也不要误选用于企业内部发行的 Enterprise Program。

准备资料：

| 资料 | 要求 |
| --- | --- |
| Apple Account | 申请人真实姓名，启用双重认证 |
| 公司法定名称 | 与公司登记和 D&B 资料一致，不用品牌名称代替法律实体 |
| D‑U‑N‑S | 9 位公司识别码；先[查已有编号](https://developer.apple.com/enroll/duns-lookup/)，没有再按官方入口申请 |
| 申请权限 | 申请人须有权代表公司签署协议；受聘开发者不能默认代替主体承诺 |
| 工作邮箱 | 应与公司域名关联，不能假填尚未开通的 `@auroradrama.app` 邮箱 |
| 公司网站 | 需公开、正常运行并能体现公司业务；仅域名停放页或极少内容的页面不被接受 |
| 联系电话及其他材料 | 按实际核验要求提供，可能需要额外公司文件 |

Apple 验证组织信息后，再签署协议并购买会员。**Apple Developer Program 标准年费为 99 美元或当地价格**；会员费不包含在阿里云域名或 BytePlus 主机费用中。

已有品牌域名和可访问的应用，不等于公司邮箱、D‑U‑N‑S 和申请人授权都已准备好。当前 Aurora 片库为空，不能仅凭技术地址可访问就保证符合 Apple 的公司网站审核要求。

## 4. “不下载 App”需要区分申请与身份核验

Apple 官方说明 **Developer Program 支持网页和 App 注册**，所以网页申请是正规途径，不必先安装 App 才能开始。

但身份核验可能有地区或账号要求。官方特别说明中国大陆账号持有人及部分地区的特定流程需要核验；若不能使用 Apple Developer App，**可联系 Apple Developer Support，申请其他身份核验方式**。能否最终全程不用 App，应以 Apple 对该账号给出的处理方式为准，不能承诺一定免除核验。

如果实际流程卡在 App，可以在 [Apple Developer Support](https://developer.apple.com/contact/)提交：

> I am enrolling our organization in the Apple Developer Program through the web. I cannot install the Apple Developer app on my current device. Please advise on an alternative identity verification method.

不要为绕过流程填写虚假地区，也不要在工单里发送账号密码或验证码。官方文档另注明印度的注册仅支持 App；不能将一般网页流程无条件套用于所有地区。

## 5. 谁来做

- **主体负责人：** 确认是否已有团队、提供真实 Team ID；没有则安排有权代表申请，完成双重认证、身份核验与会员付款。
- **开发：** 准备品牌网站、条款／隐私链接和技术资料，协助排查页面问题，拿到真实 Team ID 后填写 TikTok 后台并回查。
- **不能混同：** 阿里云邮箱验证、BytePlus 开通、域名购买、TikTok 主体资质通过，都不会自动产生 Apple Team ID。
