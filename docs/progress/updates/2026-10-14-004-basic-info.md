## Save 不发请求的原因（已复现，不再是猜测）

1. 填好其他项目，勾选网址管理权、Japan、日本地区合规确认及版权声明。
2. Apple Team ID 留空，点击 Save。
3. 页面出现唯一字段错误：**`Enter your Apple Team ID`**，输入框标记 `aria-invalid="true"`。

5. 官方页面当前加载的 `basic-info/page.91243768.js` 中，Apple Team ID 组件规则明确为 `required: true`；Save / Submit 都先执行表单校验，校验不通过就返回，不发送保存请求。

### 为什么原记录的“上传／声明完成”刷新后不见了

本次接手时重新 GET，图标引用和版权声明字段仍为空。上传图片成功，只代表图片文件已上传；弹窗内勾选并确认，只更新当页表单。两者都还需要将对应字段保存到 Basic Information。

本轮从官方页面已加载的代码确认了字段编号和请求格式，使用保存接口**只保存已有真实资料**，没有填写假 Team ID，也没有调用提审接口绕过必填要求。保存 POST 返回 HTTP 200、空对象 `{}`；随后 GET 读到了实际字段值，刷新后台页面后图标、描述、网址、Japan、版权声明和 SDK 仍保留。

## 只需补充的资料：真实 Apple Team ID

Apple 官方将 Team ID 定义为分配给开发者计划会员的 **10 位字符串**，不是邮箱、Apple 登录账号、App ID 或 TikTok Client Key。

1. 登录 [Apple 开发者账号](https://developer.apple.com/account/)。
2. 若加入多个团队，先选择 DramaVerseJP 所属的正确团队。
3. 进入 **Membership details（会员资格详情）**，复制 **Team ID**。
4. 只提供这串编号；无需提供密码、验证码或 Client Secret。

参考：[Apple 官方 Team ID 说明](https://developer.apple.com/help/glossary/team-id/)、[账号首页说明](https://developer.apple.com/help/account/basics/account-landing-page)。

如果账号只有免费开发者注册、没有相应开发者团队会员资格，不要拿邮箱或示例编号顶替；应联系所属团队管理员获取真实 Team ID，或向 TikTok 支持确认此应用的处理方式。

## 取得 Team ID 后的提审清单

1. 打开 Basic Information，确认上述已保存内容仍在。
2. 填写所属 Apple 开发者团队的真实 Team ID。
3. 检查网址管理权、日本地区合规确认框；这两项是当前页面确认状态，刷新后可能需要重新勾选。
4. 保持已验证邮箱不变，**不要重复发送验证码**。
5. 点击 Save；检查真实保存请求和响应，再 GET 确认 `apple_team_id` 值已保存。
6. 点击 Submit，核对弹窗内容，再点击弹窗中的 Submit。
7. 重新查询 Basic Information 和 Overview，确认平台显示已提交／审核中，并保存截图与实际响应。若仍为 `status: 1` 或 **Not submitted**，就没有完成提审。
8. 更新本页和首页状态，明确区分“已提审”“审核通过”“已上线”。

本地已有 Playwright 登录态文件 `/tmp/tt-state.json`；它含登录凭据，只能在本机使用，**不要提交 Git、上传网站或分享文件内容**。它的存在不保证一直有效，使用前需验证后台仍可访问。

## 官方页面实际使用的 API

```text
# 读取已保存字段
GET /tiktok/v4/devportal/mini_drama/basic_info?mini_drama_id=7696338880869500980

# 保存字段；不等于提交审核
POST /tiktok/v4/devportal/mini_drama/basic_info

# 提交审核；本轮尚未调用
POST /tiktok/v4/devportal/mini_drama/basic_info/submit

# 核实整体状态
GET /tiktok/v4/devportal/mini_drama/overall/info?app_id=7696338880869500980
```

保存请求结构如下。`fields` 是数组，不能把字段对象直接放在顶层，也不能发送空 `{}` 后仅凭 HTTP 200 宣称保存成功：

```json
{
  "mini_drama_id": "7696338880869500980",
  "fields": [
    {
      "field": 8,
      "value": "JP",
      "action": 1
    }
  ]
}
```

从官方页面字段转换代码确认的编号：

| field | 内容 |
| --- | --- |
| 1 | App 名 |
| 2 | 上传接口返回的图标 URI（不是临时图片 URL） |
| 3 | Terms URL |
| 4 | Privacy URL |
| 5 | 版权声明，字符串 `"true"` / `"false"` |
| 6 | Apple Team ID |
| 7 | 联系邮箱 |
| 8 | 发布地区，多个地区用逗号分隔；本应用只填 `JP` |
| 9 | 描述 |
| 11 | 邮箱验证状态；由真实验证码流程确认，不要伪造 |
| 12 | 最低 SDK 版本 |

保存代码会省略空字符串字段。邮箱验证流程另有 `ticket_token`；已验证邮箱未变时，不需要重复执行该流程。网址管理权确认不转换为保存字段。

实际提审请求体为：

```json
{"mini_drama_id":"7696338880869500980"}
```

**此格式只用于资料齐备后的正常提审，不能替代真实必填资料。**
