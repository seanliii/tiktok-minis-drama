## 卡点：表单字段未保存到服务端

服务端 GET `basic_info` 显示以下字段仍为空：

```json
{"description":{},"terms_of_service":{},"privacy_policy":{},"copyright_confirmation":{},"region":{},"min_sdk_version":{}}
```

**现象**：页面填完所有字段后点 Save / Submit **不发出任何 API 请求**（Network 面板无 POST），怀疑是隐藏必填项（如 Apple Team ID）或 React 表单状态未同步导致前端静默校验失败。
