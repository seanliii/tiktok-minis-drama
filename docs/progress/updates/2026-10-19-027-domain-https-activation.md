## 2. 香港 HTTPS 服务已经真正启用

本轮完成：

1. 将主域名及 `www` 解析到已购香港主机，并直接查询两台权威 DNS 核对。
2. 安装主域名／`www` 的受信任证书。HTTP 自动跳转 HTTPS，`www` 统一跳转主域名。
3. 在已有受控生产配置中填入精确的 HTTPS 来源；原有平台密钥和随机管理员密码不改变。
4. 使用原生产启动入口验证，随后启用真实应用服务。服务进程仍只监听本机，公网由 Nginx 转发。
5. 继续保持 `paymentMode=disabled`，没有启用测试扣款或真实订阅购买。

接入前，本机部署出口 IP 改变，旧 SSH 来源限制导致连接超时。只更新了原有 SSH 规则的单一 `/32` 地址，未将管理端口开放给所有人，未开放数据库或 Node 内部端口。

**没有重新购买服务器，没有迁移现有视频空间，没有把完整后台代码公开到 GitHub。**
