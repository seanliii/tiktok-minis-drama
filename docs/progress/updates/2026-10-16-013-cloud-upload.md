## 已接入

- 后台新增云上传面板；缺少配置时明确不可用，不在 local 模式假签云凭据。
- 管理员可排列多集 MP4，核对后顺序上传；支持同页暂停、继续、取消。
- 后端通过官方 STS SDK 获取 900 秒、限定空间的上传权限；长期密钥留在后端。
- 服务器持久化任务，核对 BytePlus 实际视频标记、空间、大小、格式和未发布状态，再查询 TikTok 可见性。
- 上传完成但核验失败时，重试的是相同 VID，不再次传文件。
- 页面刷新后可以找回任务；有 VID 可继续核验，没有 File／分片上下文则明确不能跨页续传。
- 原有本地上传、Cookie 管理员、Minis 用户会话、订单、支付和平台发布校验没有替换成新模拟流程。

操作与配置见[云端直传手册](/guide/cloud-upload)。

## 实际发现并修正

1. **无效 VID 抢占**：错误任务提交别人的 VID 会在验证前占用全局唯一绑定，阻止真正属于该视频的任务。先用路由测试复现，再拆开候选与已核实绑定；错误请求不再占住正确视频。
2. **父子首次读取冲突**：云面板读取配置时通知父级 busy，父级因此跳过首次剧目列表加载，导致不能选目标。浏览器实测复现后，仅放开安全的列表读取，上传及修改仍互相限制。
