# 024 · 真实上传和香港主机已经向前推进

唯一目标仍为 **Aurora Drama，日本首发**。

**本轮已完成真正的 BytePlus 上传与服务端核验，香港业务主机也已创建并通过 SSH 登录。** 这不是仅写了目标或填好配置；但还没有完成生产 HTTPS、TikTok 绑定、端内播放、真实收费或最终提审。

## 1. 登录与 IAM 已不再是旧状态

已通过 macOS 的 Chrome 脚本接口，精确连接到负责人确认的浏览器进程和标签。不能再把另一个独立浏览器停在拼图页面，误判为负责人没有登录。

已创建并回查：

- 限定视频空间的上传策略，只有 `ApplyUploadInfo`、`CommitUploadInfo`。
- 专用上传角色，信任关系仅包含现有后台服务用户。
- 后台签发者策略，只能代入指定角色，并查询所需的媒体信息。
- 后台服务用户仍不开通控制台登录，没有新增长期云密钥，没有授予全局管理员权限。

官方 STS SDK 与应用实际使用的服务端适配器都成功取得 **900 秒临时凭据**。长期密钥留在后端，临时凭据没有写入报告、数据库或浏览器持久存储。

## 2. 真实上传发现并修复了一个本地测试没暴露的问题

第一次真实上传停在申请上传地址阶段：HTTP 状态虽然是 200，但响应中包含 `AccessDenied`。云端返回的目标资源是**带实际视频空间地域的 TRN**，与此前省略地域的示例不同。

修复前：

```text
trn:vod::<账号>:space/<空间>
```

修复后：

```text
trn:vod:<视频空间地域>:<账号>:space/<空间>
```

同时修正了 **云端上传策略、后台媒体查询策略，以及后端签发 STS 时附带的临时权限策略**。没有扩大成 `*`，没有换账号，也没有关闭权限核验。

业务主机在香港 `cn-hongkong`，视频空间仍在柔佛 `ap-southeast-1`。**这里必须使用视频空间地域，不是业务主机地域。**

验证顺序：

1. 修改测试断言后，两个地区的测试按预期失败，明确指出资源缺少地域。
2. 修正实际后端构造后，适配器测试 **78 项通过**。
3. 同步云策略并读回，再做一次真实上传；此前失败只发生在申请阶段，没有传入影片字节或盲目重复完整上传。

## 3. 真实上传已经验证到哪一层

已创建真实 VOD Web/H5 SDK 应用。控制台允许暂不填写域名，所以没有为了获取 App ID 而填写未注册域名，也没有购买播放器许可证。

随后在隔离的本地验收页中，使用项目相同版本的官方浏览器上传 SDK，实际执行：

```text
后端实际适配器签发临时凭据
  → ApplyUploadInfo
  → 视频字节 PUT 到 BytePlus 上传服务
  → CommitUploadInfo
  → 后端 GetMediaInfos 读取并核验真实媒体
```

核验结果：

| 项目 | 已确认结果 |
| --- | --- |
| 文件来源 | 本机生成的测试图案与测试音，不含商业短剧素材 |
| 视频 | 5 秒、720×1280、H.264／AAC |
| 源文件大小 | 1,179,432 字节 |
| 归属 | 指定的日本项目专用视频空间 |
| 标题 | 与本次服务端生成的唯一标记一致 |
| 发布状态 | **Unpublished，未发布** |
| 浏览器持久存储 | 本次验收页 localStorage／sessionStorage 均为空 |
| 原片访问设置 | 上传前回查为 Private，保留 URL 签名设置 |

**这证明了真实 BytePlus 浏览器上传和服务端核验，不等于整个运营后台已经在生产环境跑通，更不等于 TikTok 已经能播放。** 平台绑定、平台媒资登记及端内播放仍需继续验收。

另做了三次真实权限边界检查：

- 临时上传身份查询媒体：被拒绝。
- 临时上传身份申请其他空间：被拒绝。
- 长期签发者身份不代入角色而直接申请上传：被拒绝。

不同接口返回 `AccessDenied` 或 `RequestForbidden.AccessDenied`，保留了原始错误码，不把 HTTP 200 当作成功。没有通过真实删除或发布操作来测试权限。

## 4. 香港业务主机已创建

已按负责人选定的 BytePlus 香港方案，只创建 **一台按量实例**：

| 项目 | 实际配置 |
| --- | --- |
| 区域 | 香港，可用区 C |
| 规格 | `ecs.g4i.large`，2 vCPU／8 GiB |
| 系统 | Ubuntu 24.04 LTS，安全加固镜像 |
| 系统盘 | 40 GiB |
| 独立数据盘 | 100 GiB，不随实例删除 |
| 公网 | BGP，按实际出流量计费，10 Mbps 上限 |
| 登录 | 项目专用 SSH 密钥；只导入公钥 |
| 网络 | 专用 VPC、子网和安全组 |
| 入站 | HTTP／HTTPS；SSH 限制至部署出口地址，保留组内通信 |

控制台已显示运行中，随后 SSH 登录读到了正确主机名、Ubuntu 版本、40 GiB 系统盘和未格式化的 100 GiB 数据盘。

创建前配置页报价为 **0.1256 美元／小时**，按 720 小时估算约 **90.43 美元／30 天**；普通公网出流量 **0.153 美元／GB**另计。视频、独立备份与适用税费另算；不是含所有用量的固定月账单，没有购买包年套餐。

**主机运行中不代表应用已上线。** 磁盘初始化、Node.js、应用构建、服务管理、HTTPS、独立备份及恢复仍须逐步验证。
