# 028 · 面向用户的法律入口不再使用个人 GitHub 域名

负责人要求把服务条款、隐私政策及由它们提取的服务域名切到 **Aurora Drama 自有域名**。

**本轮已部署、更新后台并实际回查：**

| TikTok 字段 | 当前正式地址 |
| --- | --- |
| 服务条款 URL | https://auroradrama.app/terms.html |
| 隐私政策 URL | https://auroradrama.app/privacy.html |
| 服务域名 | https://auroradrama.app |

“服务域名”由两条法律 URL 自动提取，不需要再独立填一个域名。**这次不是仅改了表单显示：服务端保存值和页面刷新后的值都已经是新地址。**

## 1. 不是把空应用页面当作法律页面

改动前，在新域名直接访问 `/terms.html` 或 `/privacy.html`，虽然会返回 HTTP `200`，但实际是应用首页外壳，不是法律正文。本次增加了真正的独立日文 HTML 页面。

- 精确提供 `/terms.html`、`/privacy.html`，兼容无后缀 `/terms`、`/privacy`。
- GET／HEAD 直接返回法律文件，不跳转到 GitHub，不要求登录或启用 JavaScript。
- 无第三方脚本、追踪、评论组件或外部资源。
- 页面只链接品牌主页及两份法律文书，不挂个人 GitHub 地址。
- 只增加固定页面路由，不开放任意文件目录，不修改账户、订单、付款或媒资权限。

使用原有法律文件逐段核对：条款 25 个文本块、隐私 23 个文本块的正文与顺序一致，**运营公司、原联系邮箱和 2026-10-17 的正文更新日期都保留**。本次属于迁移和展示调整，不代表新增法律承诺或完成法律合规审查。

## 2. 用户实际能点到新地址

个人中心“設定とプライバシー”中的两条入口已改为品牌域名，真实浏览器逐一点击后打开正确正文。

同时修改了 Minis 包内域名清单：增加品牌 API／视频来源，移除个人 GitHub；其他平台来源不动。TikTok 开发配置里的信任域名也已更新并刷新确认，只保留：

- `https://auroradrama.app`
- `https://video.auroradrama.app`

没有更改 Webhook，也没有把旧个人域名继续留作当前法律入口。公开技术交接站仍用于协作和历史记录，不是这两份法律文件在 TikTok 中的官方链接。

新版前端已由官方 CLI 构建、检查并上传为 **Aurora 版本 3**。包内 27 个文件、157,982 字节，不包含法律 HTML、服务端、数据库或秘密；整个包已核对没有个人 GitHub 域名字符串。法律 HTML 单独留在品牌域名的服务端，不复制进 Minis 包。

## 3. 后台为何不能只点一次“保存”

当前 Aurora 的基础信息表单会同时校验尚未填写的 **Apple Team ID 和联系邮箱**，因此普通“保存”按钮没有发出请求。

本轮先确认新域名权属，再依据当前开发者后台自身的字段映射和保存接口，**只提交服务条款及隐私两个字段**：

- 保存请求返回成功后再次 GET，确认两项 `live_value` 都是新 URL。
- 再刷新页面，确认服务域名已自动变为 `https://auroradrama.app`。
- 对照姓名、图标 URI、描述、地区、SDK、Team ID、邮箱验证和版权字段，确认其他资料未改变。
- 没有填写假的 Team ID、改成已验证邮箱、勾选未知版权声明或调用审核提交接口。

**基础信息仍未完成提审条件。** 保存法律 URL 与申请审核是不同动作。

## 5. Apple Team ID 不要求先下载安装 App

**先检查公司是否已有 Apple 开发者团队。** 有的话，登录 [Apple Developer 账号](https://developer.apple.com/account/)，在 **Membership details** 查看 10 位 Team ID，不需要重买会员或安装 Xcode。

没有会员时，可从 [网页注册入口](https://developer.apple.com/programs/enroll/)申请 **Apple Developer Program**；公司按 Organization 类型，由有权代表办理。标准会员费为每年 99 美元或当地价格，组织还需要 D‑U‑N‑S、公司域名邮箱及可用的公司网站等资料。

必须区分“网页注册”与“身份核验”：Apple 的部分地区或账号流程可能要求额外身份验证。如果设备无法安装 Apple Developer App，官方说明可[联系支持申请其他核验方式](https://developer.apple.com/help/account/membership/identity-verification/)，**不是保证所有地区都能跳过 App 或身份核验**。

详细步骤、官方链接和主体／开发分工见 [Apple Team ID 网页办理说明](/guide/apple-team-id-web)。不要用邮箱、公司登记号、D‑U‑N‑S 或外包开发者个人团队编号代替公司的真实 Team ID。
