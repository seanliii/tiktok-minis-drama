现有 GitHub Pages 地址及条款／隐私 URL 保持不变，因此不需要为了此次文档更新修改 Aurora 后台已经填写的链接。

## 2. 公开范围

本轮使用独立的 `codex/aurora-public-docs` 分支，从原公开 `main` 创建，**不合并本机完整开发分支的历史**。

允许公开的内容：

- `docs/` 中的说明、公开截图和品牌文件；
- 公开仓库的 `README.md`；
- 文档构建使用的根目录 `package.json` 和锁文件。

新增业务后台源码、真实 `.env`、用户数据、数据库、原始付款通知、登录会话、密钥和备份**均不在发布范围内**。原有公开 `app/` 和 GitHub 工作流不作修改。

## 3. 验证与发布步骤

发布前重新执行：

1. 独立发布工作区的锁文件安装、依赖审计和带实际 Pages 子目录的文档构建。
2. 手机／桌面浏览器查看首页、条款、隐私和最新交接；检查品牌图标、非空页面、运行异常和横向溢出。
3. 检查 PR 文件范围及提交历史，确认没有新增业务源码或运行数据。
4. 创建并合并 PR，保留提交编号，等待对应 GitHub Pages 工作流真正成功。
5. 直接打开公开 URL 重新核对页面、图标和最新版本内容。不能把 PR 创建、合并或工作流排队当作网站已经更新。

**本页当前是发布执行记录。实际 PR、工作流与公网页面核验结果将在完成后补齐。**
