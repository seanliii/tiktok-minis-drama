## 1. 这轮完成的开发

### 云端草稿登记

已核验并导入的云视频，现在可以从管理后台继续登记为 TikTok 草稿：

```text
云上传与核验 → 导入本地草稿单集 → 保存真实剧目资料
→ 短期提供封面 → 创建／更新平台草稿 → 查询核对单集映射
→ 交给原有媒资面板继续审核、授权、上架
```

- 保存任务、原始请求编号、平台 Album ID、版本及回执，超时不会盲目重建。
- 已生成平台版本但查询失败时，只查询原版本；先恢复单集映射，再允许准备新资料。
- 未配置实际 HTTPS 服务和平台确认的日语枚举时，登记明确不可执行。
- 封面使用可撤销的短期下载授权，不为此公开原视频；换机备份清除临时授权而保留登记业务记录。
- 登记成功不会自动提审、授权、上架、发布本地片库或发放付费权益。

运营步骤、配置与异常恢复见[平台草稿登记手册](/guide/platform-registration)。

### 负责人／财务配合

1. **BytePlus 账务与企业资料**：本人在官方控制台完成付款方式；补真实注册号、证件及有权确认的声明。卡号、安全码和验证码不发到公开文档或聊天。

3. **Aurora 应用资料**：提供所属 Apple 开发者团队的真实 Team ID，而不是邮箱；完成这款 App 的联系邮箱验证与必要声明。

### 仍由开发负责

1. 资源到位后部署 HTTPS 业务后端、管理页、持久化数据、独立备份及告警；用户、订单和观看权益随同一业务系统部署，不需要另买一套用户系统。
2. 开通视频空间及最小权限，绑定 Aurora，实测上传、核验、草稿登记、审核后播放和弱网恢复。
3. 向平台确认日本 `language` 配置及订阅正式通知契约，配置真实商品档位、支付通知与信任域名。
4. **正式订阅仍有开发，不是只剩测试**：将套餐报价、开通／重新启用、合同与每期订单、有效期和退款接到实际通知。已有收件箱、查询和 SDK 适配不能代替完整履约。
5. 在官方环境和 iOS／Android 真机验证登录、续看、单次解锁，以及订阅开通、续费、取消后本期保留、到期、欠费、退款、恢复购买、重复／延迟通知和跨设备权益。
